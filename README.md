# YCPU-8 — 8-bit Processor

YCPU-8 is an intermediate-level 8-bit processor designed and simulated using Verilog HDL.

## Features
- Program Counter
- Instruction Memory and Decoder
- Control Unit
- Register Bank and Datapath
- Arithmetic Logic Unit (ALU)
- Data Memory
- Arithmetic, logical, jump, and HALT instructions
- Testbench-based verification

## Tools
- Verilog HDL
- Icarus Verilog
- Vapor View
- Visual Studio Code

## Project Status
Intermediate learning project. The processor has been simulated, including successful verification of the JZ instruction.
